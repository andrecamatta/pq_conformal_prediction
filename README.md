# pq_conformal_prediction

Código de apoio à série **"Predição conformal para quants"** da publicação [Pílulas de Quant](https://pilulasdequant.com.br), de André Camatta.

A série cobre fundamentos teóricos e aplicações de predição conformal em finanças quantitativas, com implementações reprodutíveis.

## Artigos da série

| # | Tema | Diretório |
|---|------|-----------|
| 02 | Intervalos de previsão em regressão: CQR e CV+ aplicados a retornos do Ibovespa | [`02_regressao_cqr/`](02_regressao_cqr/) |

Cada subdiretório contém o código, os dados de entrada e instruções de reprodução do artigo correspondente.
